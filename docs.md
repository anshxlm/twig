## Introduction
Twig is a command-line version control system built on NodeJS and distributed through npm. It is designed to capture snapshots of your work reliably and efficiently, allowing you to track the complete history of a project with speed. It has the core features of a version control system, including repository initialization, commits, branching, merging, history inspection, and synchronization with its own remote. Files are stores in a space efficient manner identical file contents are never stored more than once within a repository. Twig also includes **Twix**, a hosting platform for remote repositories.
